# Changelog

## 0.1.0 — first public release

- **Design**: rectangle, ellipse, polygon, pen and text tools; move, scale, rotate, align, duplicate, nudge, undo/redo; snap to grid with a zoom-adaptive grid.
- **Text**: 16 bundled OFL fonts, uploaded TTF/OTF fonts and Google Fonts via Fontsource, with previews in the font picker; multi-line text, alignment, line height, letter spacing, bend and mirror.
- **SVG import**: paths, basic shapes, transforms and groups.
- **Materials, bits and cut settings** with recommended feeds and speeds, bit overrides and machine presets.
- **Selectable work zero** (stock corner, centre or custom offset; Z at the stock top or bottom).
- **Cuts**: outline (outside, inside or on the path, with tabs kept off corners), pocket and V-carve; two-stage carves with a rough and a detail bit.
- **Simulate**: 2D toolpath overlay, 3D preview of the carved result, warnings, estimated time and toolpath animation.
- **Export**: GRBL-compatible G-code, one file per bit, with optional custom start and end G-code.
- **Projects**: browser autosave, project list and `.oc` files (format version 2).
